# Трактор — веб-пульт

Локальный веб-пульт для macOS, RF-Nano и проверенной модели Huina 1594.
Сервис запускается на Mac, к которому плата подключена по USB. GitHub хранит
исходники; облачный сервер для управления не используется.

## Подготовка после клонирования

Нужны Python 3.9 или новее, Arduino CLI и USB-кабель с передачей данных.
Python-пакеты устанавливать не требуется. Для C++ проверок нужны Xcode Command
Line Tools. Проект настроен под RF-Nano с ATmega328P, **CE=D10, CSN=D9** и новым
загрузчиком Nano (`arduino:avr:nano:cpu=atmega328`). Для другой ревизии платы
сначала проверьте её разводку.

```sh
git clone https://github.com/GeorgiyAshkar/tractor_remote.git
cd tractor_remote
python3 --version
arduino-cli core update-index
arduino-cli core install arduino:avr@1.8.8
arduino-cli lib install RF24@1.6.2
```

Arduino CLI должен быть доступен через `PATH` или находиться в `~/.local/bin`.
Во втором случае в командах подготовки замените `arduino-cli` на
`~/.local/bin/arduino-cli`; скрипт прошивки найдёт его сам.
Библиотека RF24 нужна для сборки прошивок, включая веб-пульт.
Проверены Arduino CLI 1.5.1, AVR core 1.8.8 и RF24 1.6.2; команды выше
фиксируют проверенные версии core и библиотеки.

## Прошивка и запуск

Для новой платы сначала установите [прошивку веб-пульта](rf_nano_controller/README.md).
Если веб-сервис уже работает, остановите его через `Ctrl+C` в его окне Терминала.
Подключите RF-Nano и выполните:

```sh
./Прошить\ плату.command
./Запустить\ пульт.command
```

Скрипт прошивки выбирает единственный USB-порт. Если их несколько, он перечислит
их: подставьте нужный вместо `ИМЯ_ПОРТА`:

```sh
./Прошить\ плату.command /dev/cu.usbserial-ИМЯ_ПОРТА
```

Уже настроенную плату при обычном запуске перепрошивать не требуется. Можно
открыть [Запустить пульт.command](Запустить%20пульт.command) двойным щелчком.
Окно Терминала оставьте открытым; `Ctrl+C` останавливает сервис. Страница пульта:
**http://127.0.0.1:8765**.

Пульт автоматически проверяет USB-плату RF-Nano и сообщает, если её нужно
подключить. Питание трактора подтверждается галочкой на странице: включите
трактор и выключите штатный пульт. Кнопки работают удержанием; **СТОП**, пробел
и `Esc` прекращают передачу.

Настройки радио относятся к проверенному экземпляру. Клонирование проекта само
по себе не выполняет привязку к другой модели или пульту.

## Демонстрация и проверки

Без USB и радиопередачи:

```sh
python3 -B web_control/server.py --demo --port 8766 --open-browser
```

Проверки из корня проекта:

```sh
python3 -B -m unittest discover -s web_control -p 'test_*.py'
python3 -B web_control/tests/test_frontend.py
python3 -B rf_nano_controller/tests/verify_packets.py
python3 -B rf_nano_controller/tests/verify_captured_fixtures.py
```

Состояние счётчиков создаётся локально в `web_control/runtime/state.json` и не
переносится через Git. Перенос управления той же моделью на другой Mac описан
в [инструкции веб-пульта](web_control/README.md).

## Данные публичной версии

Полные записи эфира, в которых может быть посторонний радиотрафик, фотографии,
PDF и локальные журналы сеансов не публикуются. Для независимых проверок
оставлены отобранные кадры HS6200 в
`rf_nano_controller/tests/fixtures/hs6200_captured_frames.json`, с номерами строк
и SHA-256 исходников. Начальное значение счётчика новой установки задаётся в
`web_control/config.json`; рабочее состояние хранится отдельно на вашем Mac.
